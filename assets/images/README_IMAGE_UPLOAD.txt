# Temple Image Upload Guide
# ========================
# Save your temple images in THIS folder (assets/images/) using the naming scheme below:
#
# FORMAT: {templename}{number}.jpg  (or .png / .jpeg / .webp)
#
# EXAMPLES:
#   kochitirumaladevesowm1.jpg   ← First image of Kochi Thirumala Devaswom
#   kochitirumaladevesowm2.jpg   ← Second image of same temple
#   kochitirumaladevesowm3.jpg   ← Third image
#
#   shrimangeshi1.jpg
#   shrimangeshi2.jpg
#
#   shrishantadurga1.jpg
#   shrishantadurga2.jpg
#
#   mangalorevenkataramana1.jpg
#   mangalorevenkataramana2.jpg
#
#   kashimath1.jpg
#   kashimath2.jpg
#
#   gokarnapartagali1.jpg
#   gokarnapartagali2.jpg
#
# After uploading images here, they will automatically display on the website
# because js/data.js references them using the same naming pattern.
#
# To add more images or temples, edit js/data.js → TEMPLES_DATA array.
